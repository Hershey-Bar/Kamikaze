YOLO-World open-vocabulary detection (beverage can / smartphone domain gate), 1280-d MobileNetV3-Large identity embeddings and DINOv2 ViT-S/14 viewpoint descriptors run on the Hexagon NPU via the QNN TFLite delegate (Arm CPU fallback). Confidence is a sigmoid calibration of the cosine score, smoothed with an EMA. No camera image is ever saved: only embedding vectors (1280-d identity, 768-d DINOv2 pose) reach enrolled_classes.pt; the live view holds one in-RAM frame (/api/stream).
